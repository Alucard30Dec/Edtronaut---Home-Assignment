UI did not boot correctly

The HTML loaded, but the React/Vite module did not start. This is usually caused by running a non-Vite server on port 5173 or a module compile error.

  1. Open http://localhost:5173/@vite/client. It must return JS.
  2. Open Browser DevTools Console and check the first red error line.
  3. Run frontend with npm run dev -- --open inside frontend/.
